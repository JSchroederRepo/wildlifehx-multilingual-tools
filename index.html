WildlifeHX — Multilingual Species Tables

Translate any species name into many languages, or turn an eBird trip report / iNaturalist project into a multilingual species table. CSV/TSV export included.

Where the names come from

For birds, names use the Cornell/eBird taxonomy common-name sets — the same namesets Birds of the World uses (American English, German, French, Spanish, Norwegian, Danish, Swedish, Finnish, Dutch, Polish, Russian, Chinese, Japanese). The eBird taxonomy does not expose true British English names reliably, so “British English / alternates” is still drawn from iNaturalist’s alternate-English list as a best-effort cue (it may include non-British alternates — treat it as a cue to double-check). For non-bird taxa, all names come from iNaturalist’s vernacular-name records by locale. If the wrong species appears, pick another match above.
